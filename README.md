# Beauty-Salon-Website

Lumière Beauty Salon — responsive website built with Next.js, React, and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- Next.js 16
- React 19
- Tailwind CSS 4
- TypeScript
